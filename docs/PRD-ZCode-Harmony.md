## 1. 产品概述

### 1.1 一句话定位

ZCode Harmony 是 ZCode 本地 Server 的**鸿蒙原生遥控工作台**：AI Agent 在你自己的电脑上执行，手机/平板随时接手控制——批准工具调用、审查代码 diff、推进任务，数据全程不出本机。

### 1.2 价值主张

1. **数据主权**：代码库、执行过程、产出文件全部留在用户自己的 PC/NAS 上；app 与 Server 直连，不经过任何第三方云（华为云仅存加密的连接档案，密钥在设备端）。
2. **移动掌控**：离开工位后任务不断线——锁屏收进度、实况窗看状态、一键批准/拒绝，把"等待 agent 干活"的时间还给生活。
3. **原生生快**：不是 WebView 套壳。ArkUI 声明式渲染 + 鸿蒙系统级能力（实况窗、服务卡片、跨设备接续、小艺意图），做到"比桌面端在浏览器里更快、比网页版更顺手"。

### 1.3 目标用户

- 已经在桌面使用 ZCode 的开发者（核心种子用户）；
- 本地部署 AI Agent、关注数据安全的效率用户；
- 拥有 HarmonyOS NEXT 设备（手机 / 折叠屏 / 平板 / 2in1）的移动办公人群。

### 1.4 竞品参照

| 产品 | 借鉴点 | 差异点 |
| --- | --- | --- |
| MiniMax Agent（鸿蒙版） | 云端任务 + 移动端跟进、会话跨端同步的产品形态 | 我们执行端在用户本机，数据不出门 |
| 豆包 | 输入舱交互：语音、附件、快捷指令、打字机流式输出 | 我们多一层"工具调用批准"与"代码 diff 审查"职责 |
| Tencent WorkBuddy | 三区结构：任务列表侧边栏 + 对话区 + 结果区（产物/文件/变更/预览）；多任务并行 | 我们是遥控端，不做本地执行 |

### 1.5 明确不做的事（Non-Goals）

- 不在手机端执行 Agent、不跑模型、不管理本地代码库；
- 不做模型订阅/计费（模型授权在 Server 端完成）；
- M1 阶段不做厂内会话数据云备份（会话数据以 Server 为唯一事实源）。

## 2. 产品架构

### 2.1 分层架构

```
┌─────────────────────────────────────────────────────┐
│ 身份层  华为账号（Account Kit）— 只做"我是谁"与配置漫游     │
├─────────────────────────────────────────────────────┤
│ 配置层  Server 档案（地址+token，端侧加密 + AGC 云数据库密文）│
├─────────────────────────────────────────────────────┤
│ 数据层  App ↔ 用户本地 ZCode Server 直连（HTTPS + WSS）    │
│         会话 / 任务 / diff / 文件全部走这一层，账号不经过     │
└─────────────────────────────────────────────────────┘
                    │
                    ▼
        ZCode Server（用户 PC / NAS，既有产品）
          ├─ Agent 运行时 + 代码库 + node-pty
          └─ 模型授权（厂家账号/API Key 在此配置一次，全端共享）
```

**设计铁律：登录与连接解耦。** 华为账号是通讯录，Server 才是数据本尊。华为云不可用时，本地缓存的连接档案仍可直连，功能不降级。

### 2.2 通信协议

- 复用 ZCode 既有协议：REST `/api` + WebSocket `/ws`，协议层直接复用 `@zcode/client`（纯 TS，ArkTS 兼容，去除 Node API 后以源码形式引入）。
- App 永远是"瘦客户端 + 本地缓存"：会话历史首次进入全量拉取，此后走 WS 增量推送。

### 2.3 Server 端配套改造（见第 8 章清单）

配对二维码、访问 token 鉴权、TLS、mDNS 发现、Push 服务端回调。

## 3. 核心场景（用户故事）

**S1 首次配对**：开发者在桌面端打开"设置 → 移动端配对"，出现配对二维码；手机 app 扫码，3 秒完成绑定，首屏即见桌面端正在跑的会话。

**S2 外出盯任务**：在公司让 agent 重构一个模块，地铁上锁屏收到实况窗"任务等待确认：是否执行 `rm -rf dist`"，点开是 diff 卡片，左滑拒绝右滑批准，全程不掏电脑。

**S3 平板接续审查**：回家后打开平板（同华为账号），任务接续展示，大屏看完整 diff 与产物预览，批准合并。

**S4 断网恢复**：进电梯断网，出电梯 app 自动重连 WS，会话从断点继续流式输出，无感恢复。

- 分组：进行中 / 今日 / 更早；置顶、重命名、归档；

- 顶部搜索（标题 + 内容全文，Server 端搜索接口）；
- 新建会话光感主按钮常驻抽屉头部。

## 5. 体验设计规范（Design Guideline）

### 5.1 设计原则

1. **速度感即体验**：所有动效服务于"感知提速"——流式无闪烁、转场无白屏、按压必有响应（≤100ms 视觉反馈）。
2. **一手持机，拇指优先**：核心操作（发送、批准/拒绝、Tab 切换）全部落在屏幕下 1/3 安全区内；批准/拒绝支持手势完成。
3. **状态永远可见**：连接态、任务态、生成态三态常显，用户在任何页面都知道"agent 现在在干嘛、是否在等我"。
4. **克制用色**：遵循 ZCode 规范"语义色只用于真实语义"；光感效果仅保留给主行动与确认类动作，全屏辉光元素同屏 ≤1 个。

### 5.2 HarmonyOS Design（HSD）× ZCode 风格融合

- 布局与控件基座遵循 HSD：系统字体（HarmonyOS Sans）、栅格与间距 token、系统转场、大标题导航；
- 色彩体系整体映射 ZCode 语义 token（深色为默认主题，开发者工具基因）：

| ZCode token（事实源） | 鸿蒙资源命名 | 用途 |
| --- | --- | --- |
| `--color-background` | `zcode_bg` | 页面底 |
| `--color-card` / `--color-surface` | `zcode_card` / `zcode_surface` | 卡片/容器 |
| `--color-foreground`（含 subtle / subtlest） | `zcode_text_primary/secondary/tertiary` | 文字三级 |
| `--color-brand` | `zcode_brand` | 光感光源色、主行动 |
| `--color-success / warning / destructive` | `zcode_success / warning / destructive` | 状态与批准/拒绝 |
| `--color-diff-added / removed` | `zcode_diff_add / diff_del` | 代码 diff |
| `--color-workflow-trace(-strong)` | `zcode_trace / trace_strong` | 任务时间线 |
| `--color-interaction-confirmation-*` | `zcode_confirm_*` | 等待确认徽标（统一绿色确认态，禁止用 success 替代） |

- 抽屉、单列会话、工作台密度遵循 ZCode 移动端既有规范（单列 + 抽屉）。

### 5.3 光感设计语言：参数与使用边界

光感（Light Bloom）是本产品的品牌识别点，定义四级，逐级减弱：

| 级别 | 元素 | 效果 |
| --- | --- | --- |
| L1 | 主行动按钮（发送/批准/新建） | 渐变填充 + 顶部内高光 + 外辉光 |
| L2 | 输入舱聚焦态 | 边缘 1px 品牌色泛光，呼吸周期 3s |
| L3 | 状态浮标（回到底部/新会话提示） | 底面辉光，无渐变 |
| L4 | 完成时刻 | 任务全部完成的单次庆祝微光扫过（600ms，一次性） |

### 5.4 HSD 沉浸光感按钮规范（核心控件）

**结构**（自下而上）：

1. **底色渐变**：`linearGradient(135°, brand@100% → brandLight@100%)`，圆角 = HSD 胶囊圆角（高度的一半）；
2. **内高光**：顶部 inset 线性高光 `white 24% → transparent`，高度 40%，模拟玻璃弧面受光；
3. **外辉光**：`shadow({ radius: 24, color: brand@35%, offsetY: 4 })`；暗色主题下 radius 增至 32、透明度 45%（暗场辉光更明显）；
4. **内容层**：图标 + 文案 `brand-contrast` 色。

**状态机与动效**：

| 状态 | 表现 |
| --- | --- |
| default | 静态辉光；呼吸微光周期 3s（透明度 35%↔45%，仅 L1） |
| pressed | `scale(0.96)` + 辉光半径收缩至 16 + 高光增亮（受压变亮，物理隐喻），`curves.springMotion(0.4, 0.8)` |
| released | 回弹 `scale(1)` + 一次光晕扩散涟漪（从按压点扩散，400ms，`curve: curves.cubicBezierMotion(0.2,0,0,1)`） |
| loading | 光带流动：45° 高光条沿按钮平移循环（1.2s/圈），文字置灰 |
| disabled | 去辉光、渐变降为 40% 饱和度、文字 tertiary |
| destructive 变体 | 描边样式替代填充：destructive@60% 描边 + 文字 destructive，按压时描边泛红光（用于"拒绝/停止"，与主行动形成强对比） |

**触感**：按压 `Vibrator` 轻触感（10ms），批准/拒绝确认成功时双击感（短-短），错误时长振（40ms）。

**禁用规则**：列表项、次级按钮、标签一律禁用辉光；同屏 L1 按钮唯一（吸底批准对除外——批准与拒绝互为 L1/L1' 时，拒绝走 destructive 描边变体）。

### 5.5 动效系统

- **转场**：会话列表 → 会话页使用系统共享元素转场（卡片一镜到底）；抽屉用系统侧滑手势，支持边缘右滑返回；
- **流式**：新消息入场 `translateY(8) + opacity 0→1`，120ms；"正在思考"三点波 + 工具卡片状态灯脉冲共用同一节奏（1s 周期），建立统一心跳感；
- **数字/进度变化**：+n/−n 徽标变化用数字滚动（300ms）；
- **降级**：系统"减弱动态效果"开启时，保留透明度过渡、移除位移与辉光呼吸。

### 5.6 多设备自适应（一多）

- 手机：单列 + 抽屉；折叠屏展开态/平板：双栏（左会话列表 280vp + 右工作台），产物 Tab 在宽屏下右分栏（WorkBuddy 桌面式结果区）；
- 断点：`sm(≤600) 单列 / md(601–840) 双栏-抽屉默认收起 / lg(>840) 双栏常驻`；
- 横屏、悬浮窗、PC 2in1 均以 lg 断点复用双栏。

### 6.2 流式渲染管线（体验核心，重点工程）

```
WS chunk → 消息缓冲区（16ms 合帧）
  → TaskPool: 增量 markdown 解析（复用上一帧 AST，仅重算尾块）
  → 节流上屏（≤60fps；代码块/公式等重节点单独降频）
  → LazyForEach 按"块"复用组件，长会话只挂载可视区 ±5 屏
```

- 代码块高亮结果缓存（按 语言+内容 hash），流式中代码块每 200ms 批量刷新一次，避免逐字高亮抖动；
- 图片/产物懒加载 + 降采样解码。

### 6.3 性能指标（验收线）

| 指标 | 目标 |
| --- | --- |
| 冷启动（点图标 → 首屏可交互） | ≤ 800ms |

| WS chunk 到达 → 上屏 | ≤ 50ms（不含网络） |

## 7. 技术方案要点

### 7.1 工程结构（DevEco Studio，hap 多模块）

```
zcode-harmony/
├─ entry/                 # 主入口：工作台、会话、设置
├─ features/
│  ├─ pairing/            # 配对向导、扫码、发现
│  ├─ workspace/          # 会话工作台（对话/产物/变更）
│  ├─ connection/         # 连接管理、重连引擎
│  └─ account/            # 华为账号、配置云同步（P1）
├─ commons/
│  ├─ protocol/           # @zcode/client 移植（RPC/WS/类型）
│  ├─ uikit/              # 光感按钮、状态灯、diff 卡片等组件库
│  └─ utils/
└─ AppScope/
```

### 7.2 协议层移植策略

- 从 `packages/client`、`packages/rpc`、`packages/shared` 源码级引入，做 ArkTS 兼容改造：去 `node:` 依赖、去结构化类型、显式类型标注；WebSocket 用鸿蒙 `@ohos.net.webSocket` 适配层替换 `ws`；
- 建立协议一致性测试：移植层与原包跑同一套 JSON 套例（录制自真实 server 流量），保证行为一致。

### 7.3 安全设计

- 全链路 HTTPS/WSS；配对 token 一次性、轮换制；
- 首次连接证书固定可选（Server 端提供自签证书指纹，防局域网 MITM）；
- 隐私：不采集代码内容；崩溃日志脱敏（剔除消息正文）；华为云仅存密文档案；隐私中心标签如实申报。

## 9. 非功能需求与合规

- **上架**：软件著作权登记；华为应用市场审核（HSD 符合度、隐私标签、权限最小化说明）；
- **生成内容合规定位**：app 为"用户自有服务的客户端"，不内置模型服务、不直接向公众提供生成内容；隐私政策明确数据流向（用户 Server ↔ 设备）；该定位需在提审材料中书面说明，必要时咨询法务是否触发算法备案义务；
- **可用性**：离线态可浏览本地缓存会话（只读）；所有破坏性操作（断开 Server、清除档案）二次确认；
- **国际化**：中文优先，文案走资源表预留英文。
